# Prediksi Shio & 2D — Tujuan Pembelajaran

⚠️ **PERINGATAN PENTING**
- Proyek ini murni untuk **belajar pemrograman, kecerdasan buatan, dan analisis data**
- Hasil prediksi **bukan jaminan** kemenangan
- Data undian bersifat acak, tidak ada pola yang pasti
- **Tidak untuk berjudi atau pasang taruhan**
- Gunakan hanya untuk keilmuan & pembelajaran

Teknik yang dipakai:
- LSTM Jaringan Saraf Tiruan
- Optuna Pencarian Parameter Terbaik
- Analisis frekuensi & keterlambatan angka
